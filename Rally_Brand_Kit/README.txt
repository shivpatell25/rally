Use full-color gradient logos on deep/dark backgrounds. Use white on dark imagery where the gradient loses contrast. Use black/deep navy on light backgrounds. Transparent PNG variants contain no baked background. App icon files retain transparent pixels outside the rounded square. The primary hero uses the approved lower-saturation artwork and centers the wordmark. The PNG masters preserve the approved raster coloring; SVG gradient versions are scalable approximations.
